# Rule register

Which polyglot-clean-code rules this repository enforces, which engine checks each one, and
where it deviates from the presets.

This repository adopts [polyglot-clean-code](https://github.com/Archont561/polyglot-clean-code)
`v0.1.0` at the Pedantic level. The presets are vendored unchanged under
`vendor/clean-code-presets/` (pin in `UPSTREAM.pin`); local configs point at them.

## Engines

| Engine | Config | Source |
| --- | --- | --- |
| Vale | `.vale.ini` | Vendored Pedantic styles, used in place |
| ast-grep | `sgconfig.yml` | Vendored Pedantic rules, used in place |
| Alint | `.alint.yml` | Local adaptation of Strict and Pedantic (adoption path 2) |
| knip | `knip.json` | Local: unused files, exports, and dependencies |
| dependency-cruiser | `.dependency-cruiser.json` | Local: import layering, cycles, orphans |
| secretlint | `.secretlintrc.json` | Recommended preset |
| actionlint | none | Upstream defaults, from Pixi |
| zizmor | none | Offline audits, regular persona, from Pixi |
| lychee | `lychee.toml` | Local: repo links remapped to the working tree |
| Semgrep | not run | Its rules target Python, Rust, and TOML; this repository has none |

## Rules in effect

| ID | Rule | Enforced by |
| --- | --- | --- |
| PCC-S01 | No `console.log` in library code | ast-grep; Biome `noConsole` |
| PCC-S05 | No nested conditional expressions | ast-grep |
| PCC-S06 | Read `process.env` only in `tools/lib/config/` | ast-grep |
| PCC-S07 | No empty catch blocks | ast-grep |
| PCC-D01 to PCC-D06 | Canonical terms, spacing, weasel words, links, placeholders, headings | Vale |
| PCC-R02 | Automation in `tools/commands/*.ts` behind `tools/index.ts`, no `scripts/`, single-line workflow `run` steps | Alint |
| Local | `tools` is the only `package.json` script; lefthook stays trusted so its postinstall installs the hooks | Alint |
| PCC-R03 | Pinned Bun, lockfile, hooks, commit configuration | Alint |
| Local | The toolchain comes from `pixi.lock`: Bun pinned to `packageManager`, actionlint, zizmor, lychee; `pixi.toml` has no tasks; workflows use a SHA-pinned `prefix-dev/setup-pixi` with `locked` and an activated environment | Alint; tests |
| Local | No unused code or dependencies; `lib` never imports `commands` or `tests`; commands never import each other; generated clients only behind `capture` | knip; dependency-cruiser |
| Local | No committed secrets | secretlint |
| Local | Workflows are valid and free of known injection and credential patterns; Renovate waits seven days and pins action digests | actionlint; zizmor; Alint |
| Local | Links in the README and docs resolve; repo links and anchors are checked offline before every push | lychee (`links --offline` in `check`, full run daily) |
| PCC-R04 | README, AGENTS, docs index, development guide, this register | Alint |
| PCC-R05 | Read-only workflow permissions, SHA-pinned actions, a pull request template | Alint |
| PCC-R06 | No environment files or build output in the tree | Alint |
| PCC-R07 | A paired test in `tools/tests/` for every `tools/lib/` and `tools/commands/` module | Alint `pair` |
| PCC-R08 | Conventional Commit types inside the approved list | Alint; commitlint |
| Local | `docs/README.md` and the pull request template are rendered from `templates/*.ejs`: generated header, source template present, no other pull request template location | Alint; `readme --check` |

## Local deviations

| Preset rule | Deviation | Reason |
| --- | --- | --- |
| PCC-R01 Pixi manifest and lockfile | Not adopted | Bun is the only toolchain; `bun.lock` is the environment of record |
| PCC-R02 `automation/dodo.py`, `doit.cfg` | Replaced by `tools/index.ts` and `tools/commands/*.ts` | The citty CLI plays the doit role |
| PCC-R03 `.versionrc` for Convco | Replaced by `.commitlintrc.json` | commitlint checks commits; the type list is the same |
| PCC-R04 contributing guide | Not adopted | Personal repository without outside contributors; the development guide covers the workflow |
| PCC-R05 issue forms | Not adopted; `.github/ISSUE_TEMPLATE/` must stay absent | Development-only repository with no user-facing product; project issues belong to each project's repository |
| PCC-R07 rule-test pairs | Applied to `tools/lib/` and `tools/commands/` modules | This repository ships tools, not rules |
| All engines on generated code | `tools/lib/capture/clients/` is skipped by Biome, ast-grep, coverage, and PCC-R07 | Generated by Hey API and gql.tada; regenerate instead of editing |
| PCC-R08 Backlog statuses | Not adopted | No Backlog.md board here |

Move to a newer preset by updating `vendor/clean-code-presets/` and `UPSTREAM.pin` in one
commit, then run `bun run tools lint` and update this register.
